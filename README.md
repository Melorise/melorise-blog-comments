# Approved comments

This independent data branch contains only reviewed comment records at
`<article_id>/<comment_id>.json`. Review the 0721c validation check and merge
comment pull requests manually. Never run code from a comment pull request.

Do not rewrite this history or delete a parent record with existing replies.
Issue edits do not update captured records. Pending Issues and pull requests
are public but are not displayed on the website until approved and indexed.
