# 已审核评论

本分支保存网站评论的源记录，每条评论对应一个 JSON 文件：

```text
<文章 ID>/comments-<Issue 编号>.json

article/essay/hello/comments-37.json
```

评论通过审核 PR 加入本分支。合并后，发布工作流生成 `index` 分支中的文章评论树。

## 修改和删除

按文章路径找到记录。修改 `body_markdown` 可更正正文，删除记录可移除评论，删除文章目录可清除该文章的全部评论。

`reply_to` 为父评论的完整 ID。删除父评论时需同时删除其后代回复，或将受影响回复指向仍存在的父评论或设为 `null`。父评论缺失会使索引发布失败。

提交变更后检查 `0721c publish index` 是否成功。投稿规则和工作流配置见 `main` 分支。
