# Approved comments

This independent branch starts with this README only. Reviewed records live at
`<article/path>/<UTC-timestamp>-<random>.json`, for example
`article/essay/hello/20261005T020000000Z-a1b2c3d4e5f6.json`.
Comment IDs combine the readable article path, UTC timestamp and random suffix. Review the `0721c/comment-data` check
and merge comment PRs manually. Never execute code from a comment PR.

Approved records are the source of truth. Preserve parent records used by replies.
Issue edits do not replace saved records. Pending comments appear on the website
only after approval and index publication.
